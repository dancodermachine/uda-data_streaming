## Requirements
Create the following environment variables. We are using [Confluent](confluent.cloud).

```
CONFLUENT_KAFKA_SECRET
CONFLUENT_BOOTSTRAP_SERVERS
CONFLUENT_KAFKA_KEY
CONFLUENT_SCHEMA_REGISTRY_URL
CONFLUENT_SCHEMA_REGISTRY_KEY
CONFLUENT_SCHEMA_REGISTRY_SECRET
KSQLDB_ENDPOINT
KSQLDB_API_KEY
KSQLDB_API_SECRET
```
Install the necessary libraries.
```bash
pip install -r requirements.txt
```
